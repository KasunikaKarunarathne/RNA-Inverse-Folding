# RNA Inverse Folding - QUBO Model Analysis

This document provides a comprehensive analysis of the QUBO model's performance across different phases of the inverse folding pipeline, based on recent sampling and optimization runs.

## 1. Summary
The OLS-based QUBO model demonstrates exceptionally strong predictive power across the global energy landscape, maintaining overall Spearman correlations of **>0.95** for all tested structures. However, when isolating the bottom 10% of sequences (the most critical region for inverse folding), correlation slightly degrades to the **0.80 - 0.88** range. Despite this, the model reliably identifies the true ground state candidates, capturing roughly **85-90%** of the true optimal sequences in its top 10% predictions. In end-to-end forward folding tests (Phase 9), the model achieved a **28% - 38%** success rate in designing sequences that correctly fold into the target structures using a uniform random loop sampling approach.
